01 Start with structure

Meet HTML

HTML (HyperText Markup Language) describes the meaning and organization of a web page. It uses elements—the building blocks the browser reads to understand each piece of content.

< >

Elements

Most elements have an opening tag, content, and a closing tag. 

<p>Hello there!</p>

Together, the tags and content make a paragraph element.

▧

Nesting

Elements can live inside other elements. Indent nested elements to make the structure easy to follow. 

<p>Hello, <strong>web!</strong></p>

Close the inner element before the outer one.

THE STARTING POINT

An HTML document, from top to bottom

Every page begins with a small document skeleton. In index.html, find these parts near the top and match them to the notes.

  1. 1

    <!doctype html> tells the browser to use modern HTML.

  2. 2

    <html lang="en"> wraps the page; lang identifies its language.

  3. 3

    <head> holds page information, the title, and links to resources.

  4. 4

    <body> holds the content people see and interact with.

THE DOCUMENT SKELETONplayground.html 
<!-- 1. Tell the browser this is modern HTML -->
<!doctype html>
<html lang="en">
  <head>
    <meta charset="utf-8">
    <meta name="viewport"
      content="width=device-width, initial-scale=1">
    <title>My first page</title>
    <link rel="stylesheet"
      href="styles.css">
  </head>
  <body>
    <!-- Visible page content goes here -->
  </body>
</html>

↳ The <link> element connects this HTML page to its CSS file.

WHERE YOUR CODE LIVES

A web page is usually more than one file.

Keep related files together in one project folder. The browser starts with an HTML file, then follows links in that file to find its CSS, images, and other resources.

Why “index”? index.html is a common default name for a website's home page. When a web server opens a folder, it often looks for an index file automatically. Other pages can use descriptive names such as about.html or contact.html.
A SIMPLE PROJECT FOLDERmy-first-site/

  • 5index.htmlThe home page and page structure
  • ✳styles.cssStyles used by the page
  • ▧images/A folder for image files
  • ▧class-photo.jpgAn image inside the images folder
  • 5playground.htmlAnother page in the same site
  • ✳experiments.cssYour optional practice stylesheet
File names are your choice: use clear, lowercase names such as gallery.html or main.css. Avoid spaces; use hyphens when needed. The file extension matters: .html for HTML, .css for CSS, .js for JavaScript, and an image extension such as .jpg or .png for images.
Paths tell the browser where to look: styles.css is in the same folder as index.html; images/class-photo.jpg means “open the images folder, then find class-photo.jpg.” The link's href must match the real name and location.

03 Make words easy to read

Typography creates
hierarchy.

Typography is how text looks and reads: its typeface, size, weight, spacing, and line length. A clear hierarchy helps readers tell titles, sections, and body text apart and find their way through a page.

A SIMPLE TYPE SCALE

Show what matters first.

Use one clear page title, then section headings, then smaller subheadings where needed. Body text should be comfortable to read. Keep the heading order meaningful in HTML; use CSS to control how each level looks.

  • Heading: signals the topic of the page or section.
  • Body: carries the main reading content.
  • Supporting text: adds a caption, note, or secondary detail.

A PAGE ABOUT GARDENING

Growing a small garden

Choose a sunny spot

Most herbs grow well with several hours of sunlight. Start with a few plants that you enjoy using.

A simple page title, section heading, body paragraph, and caption.

Typeface & size

font-family chooses the typeface; font-size sets its size. A fallback font list helps if the first font is unavailable. 

font-family: Arial, sans-serif;
font-size: 1rem;

Weight & line height

font-weight changes how bold text appears. line-height adds breathing room between lines; it is commonly unitless. 

font-weight: 700;
line-height: 1.6;

Alignment & measure

text-align aligns text within its block. Limiting a paragraph's max-width can make long lines easier to follow. 

text-align: left;
max-width: 65ch;

USING A WEB FONT

Choose a font, then connect it.

A web font is a font file or hosted font that a page loads instead of relying only on fonts installed on the visitor's device. One option is to use a font provider such as Google Fonts; another is to host a licensed font file in your own project.

  1. Choose a font and the weights you need from a reputable provider.
  2. Copy the provider's stylesheet link into the document's <head>.
  3. Use the exact font-family name given by the provider in your CSS.
  4. Keep a generic fallback such as sans-serif in case the font cannot load.

Keep it lightweight: Use only the font families and weights you need. For a real project, check the provider's licensing and privacy guidance.

1. LINK THE FONT IN THE PAGE HEADplayground.html 
<!-- Example hosted-font stylesheet link -->
<link rel="preconnect"
  href="https://fonts.googleapis.com">
<link rel="stylesheet"
  href="https://fonts.googleapis.com/css2?family=Nunito+Sans:wght@400;700&display=swap">

Place font links in <head>, before the stylesheet that uses the font. This example requires an internet connection.

2. USE THE FONT IN A RULEexperiments.css 
body {
  font-family: "Nunito Sans", sans-serif;
}

h1 {
  font-family: "Nunito Sans", sans-serif;
  font-weight: 700;
}

The family name must match the font you loaded. The browser uses sans-serif if it cannot use that font.

PAIRING TYPEFACES

Let headings and body text work together.

A font combination pairs typefaces with different jobs—for example, a distinctive heading font with a simple, highly readable body font. Contrast helps create hierarchy, while shared characteristics help the pair feel coordinated.

  1. Choose one font for headings and one for paragraphs.
  2. Keep the pairing simple; two font families are usually enough for a beginner project.
  3. Check readability at normal paragraph size, not only in a large heading.
  4. Load both families and only the weights you plan to use.

Explore and choose

Fontjoy ↗ can generate font-pairing ideas. Treat suggestions as a starting point, then preview them with your own text.

Google Fonts ↗ lets you browse typefaces, compare styles, and get the stylesheet link and family names to use in your page.

Try it: pick a heading and body font, link both in playground.html, and assign them to headings and paragraphs in experiments.css.

TRY A CLASS SELECTOR

Style headings consistently.

Give an element a class in HTML, then use a dot before that class name in CSS. This rule applies to elements with class="page-title"; it does not change the HTML heading level.

HTML + CSSplayground.html / experiments.css 
<!-- In your HTML -->
<h1 class="page-title">My garden</h1>

/* In your CSS */
.page-title {
  font-size: 2.5rem;
  font-weight: 700;
  line-height: 1.1;
}

04 Add useful details

Attributes add
context.

An attribute is extra information written in an element's opening tag. It usually has a name and a value: name="value".

READ THIS TAG

<a href="https://example.com" class="read-more">Read more</a>
href is the attribute name"https://example.com" is its value
A

Some attributes are global

class and id can be used on many HTML elements. A class can be shared; an ID should identify one unique element on the page. 

<p class="note">Remember this.</p>
B

Others belong to specific elements

href gives an <a> its destination. src and alt describe the image source and alternative text for an <img>. 

<img src="flower.jpg"
  alt="A yellow flower">

!Remember: HTML attributes are not interchangeable. Use an attribute on elements that support it—href belongs on links, not on every tag. Always give links clear destinations and images meaningful alt text (or empty alt="" when an image is purely decorative).

05 Add the visual layer

Now, make it
yours.

CSS (Cascading Style Sheets) controls how HTML looks: colors, spacing, type, and layout. The browser combines HTML structure with CSS rules to draw the page.

01

Connect the stylesheet

The <link> element goes inside <head>. The href value is the CSS file path, relative to the HTML file.

02

Choose what to style

A selector picks the HTML element. A declaration inside braces says what property to change and what value to use.

03

Adjust the box

Each element is a box. Content sits inside padding, then border; margin creates space outside the border.

COMMON VISUAL PROPERTIES

Pick a property. Give it a value.

CSS declarations go inside a rule's curly braces. Write a property name, a colon, its value, and a semicolon. The selector chooses which elements receive the styling.

Text

Change text color, size, weight, alignment, or line spacing. 

color: #284b3b;
font-size: 1.25rem;
font-weight: 700;
text-align: center;

Background & border

Add a background color, an outline around the box, or rounded corners. 

background-color: #e6f0d8;
border: 2px solid #789346;
border-radius: 8px;

Space & size

Padding adds room inside an element; margin adds room outside it. 

padding: 1rem;
margin: 1rem 0;
width: 100%;

Layout

Choose a layout behavior and add consistent space between children. 

display: flex;
gap: 1rem;
justify-content: center;

PUT IT TOGETHER

One rule can style many elements.

This selector targets every paragraph. Change the selector to .note to target only elements with class="note". Properties are reusable, but their visible effect depends on the element and the value.

SELECTOR + DECLARATIONSexperiments.css 
p {
  color: #43594a;
  font-size: 1rem;
  line-height: 1.6;
}

Reading a declaration: in padding: 1rem;, padding is the property and 1rem is its value. The colon separates them; the semicolon ends that declaration. A rule can contain several declarations.

SIZING UNITS

How big is a rem?

CSS values often include a number and a unit. The unit tells the browser how to interpret the number. Choose a unit based on what the size should relate to.

px — pixels

A fixed CSS length, useful for fine details like a thin border. It does not literally mean one hardware screen pixel. 

border-width: 2px;
rem — root-relative

Relative to the root page font size. Often used for text and spacing so sizes can scale consistently. With a 16px root size, 1rem equals 16px. 

font-size: 1.25rem;
em — parent-relative

Relative to the current element's font size (often inherited from its parent). Useful for sizing something in proportion to nearby text. 

padding: 1em;
% — percentage

Usually relative to the containing element's corresponding size. For example, width: 100% fills the available parent width. 

width: 100%;
vw / vh — viewport

Relative to the browser's viewport: 1vw is 1% of its width; 1vh is 1% of its height. Use carefully for fluid sizing. 

width: 50vw;
Unitless numbers

Some properties, such as line-height and font-weight, commonly use a number without a length unit. 

line-height: 1.5;

Beginner tip: Start with rem for text and spacing, percentages for flexible widths, and px for small precise details. Many CSS properties accept only certain units or keywords, so check what the property expects.

LOOK UNDER THE HOOD

Explore with browser
developer tools.

Developer tools are built into browsers such as Chrome, Edge, Firefox, and Safari. They let you inspect a page, test temporary changes, and see useful debugging messages—without changing your source files.

01

Open the tools

Right-click an element in the preview and choose Inspect, or open the browser menu and choose Developer Tools. Common shortcuts include F12 or ⌘+⌥+I on Mac; shortcuts can vary by browser.

02

Inspect an element

In the Elements (Chrome/Edge) or Inspector (Firefox/Safari) panel, explore the page's HTML tree. Hover over a node to see its area highlighted in the preview.

03

Try a CSS change

Select an element and find its Styles or Rules panel. Click a value such as color and change it. You can toggle a declaration or add a temporary rule.

04

Understand the result

Edits made in developer tools are temporary: refresh the page and they disappear. To keep a change, copy the rule into experiments.css in your own fork.

THE CONSOLE

Read browser messages

The Console can show errors and warnings that help explain why something is not working. You can also run small JavaScript expressions there.
